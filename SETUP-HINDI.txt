ASTROMUL वेबसाइट सेटअप — हिंदी में
================================

इस ZIP में:
1. Code.gs — Google Apps Script का सर्वर कोड
2. Index.html — पूरी मोबाइल-अनुकूल वेबसाइट
3. ASTROMUL-logo.png — आपका लोगो
4. favicon.png और favicon.ico — फ़ेविकॉन

इंस्टॉल करने के चरण:
1. https://script.google.com/ खोलें और अपना पुराना प्रोजेक्ट खोलें।
2. Code.gs में इस ZIP वाली Code.gs फ़ाइल का पूरा कोड डालें।
3. + दबाकर HTML फ़ाइल बनाएँ। नाम बिल्कुल Index रखें।
4. Index.html का पूरा कोड उसमें डालें।
5. Save करें।
6. Deploy → Manage deployments → Edit → New version → Deploy करें।
7. Web app को Execute as: Me रखें। जिन लोगों को फॉर्म भरना है, उनके लिए उपयुक्त access चुनें।
8. अपने /exec लिंक को खोलें और टेस्ट रजिस्ट्रेशन करें।
9. अपनी Google Sheet में Astrologer Registrations नाम का टैब और नया रिकॉर्ड देखें।
